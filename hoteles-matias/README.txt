PROYECTO: Hoteles sugeridos · Bautizo de Matías André

Archivos:
- index.html: página web completa (HTML, CSS y JavaScript en un solo archivo).

VISTA LOCAL:
1. Extrae la carpeta del ZIP.
2. Abre index.html con Chrome, Edge u otro navegador.

PUBLICAR EN VERCEL:
1. Sube la carpeta a un repositorio nuevo de GitHub.
2. En Vercel, importa ese repositorio.
3. Framework Preset: Other.
4. Root Directory: dejar vacío (./), porque index.html está en la raíz.
5. Build Command: desactivado/vacío.
6. Output Directory: dejar por defecto o usar . si lo solicita.
7. Deploy.

NOTAS:
- El sitio es independiente de la invitación original.
- Google Maps abre una búsqueda del hotel y dirección; verifica el pin antes de viajar.
- Los teléfonos, direcciones y el precio fueron transcritos de las tarjetas proporcionadas. Confirma los datos con cada hotel.
